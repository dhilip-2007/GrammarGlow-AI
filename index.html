NEED A HAND?

Frequently asked questions

Does GrammarGlow use a real AI model?

This starter version uses local rule-based checks. A real AI service requires a backend and an AI provider integration.

Is my text sent to a server?

The HTML interface does not send your text to a server by itself. Browser features and any future integrations may have different data handling.

Can I download my writing?

Use the download button to save your text once the JavaScript functionality is connected.

Will every grammar error be detected?

No. Simple rules can miss errors and sometimes suggest changes that do not fit the context. Review suggestions carefully.
